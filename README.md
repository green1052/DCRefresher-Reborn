## 사용법

Chrome 140(Edge·Whale 등 크로뮴 계열 포함), Firefox 144 이상에서 동작합니다. 툴바의 확장 아이콘을 누르면 팝업이 열리고, 여기서 모듈을 켜고 끄거나 톱니바퀴 버튼으로 옵션 페이지를 엽니다.

- 목록에서 제목을 **우클릭**하면 미리보기 창이 열립니다. 원래 우클릭 메뉴는 **Shift+우클릭**으로 엽니다.
- 미리보기 창에서 **PageUp** / **PageDown**으로 앞뒤 글로 넘어가고 **Esc**로 닫습니다.
- 작성자를 우클릭하면 차단·메모 메뉴가 뜹니다.
- 단축키는 목록 새로고침 `Alt+R`, 자동 새로고침 일시정지 `Alt+S`, 스텔스 모드의 이미지 잠시 보이기 `Alt+P`입니다.

자세한 사용법은 [위키](https://github.com/green1052/DCRefresher-Reborn/wiki)에 있습니다.

## 문제 해결

- `요청이 많아 디시인사이드가 잠시 접속을 막았습니다.`가 뜨면 잠시 기다린 뒤 새로고침하세요. [요청 제한](https://github.com/green1052/DCRefresher-Reborn/wiki/requests)의 동시 요청 수를 낮추면 덜 막힙니다.
- `확장 프로그램이 업데이트되었거나 꺼져서 이 페이지에서는 멈췄습니다.`가 뜨면 페이지를 새로고침하세요.
- 그 밖의 문제는 [이슈](https://github.com/green1052/DCRefresher-Reborn/issues/new/choose)로 알려 주세요. 옵션 → **정보** → **진단 정보 복사** 결과를 붙여 주시면 원인을 찾기 쉽습니다.

## 개발·기여

[Bun](https://bun.sh) 1.4 이상과 [Node.js](https://nodejs.org) 25 이상이 필요합니다. `bun install` 뒤 `bun run dev`로 띄웁니다. 자세한 내용은 [개발 문서](docs/README.md)에 있고, 풀 리퀘스트는 `develop` 브랜치로 보내 주세요.

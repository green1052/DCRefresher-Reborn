# DCRefresher Reborn

디시인사이드 개선 확장 프로그램

## 기능

| 모듈 | 설명 |
|------|------|
| 컨텐츠 차단 | 유저, 컨텐츠 등의 보고 싶지 않은 컨텐츠들을 삭제합니다. |
| 미리보기 | 글을 오른쪽 클릭 했을때 미리보기 창을 만들어줍니다. |
| 글 목록 새로고침 | 글 목록을 자동으로 새로고침합니다. |
| 유저 정보 | 사용자의 IP, 아이디 정보, 메모를 표시합니다. |
| 메모 시스템 | 유저별 색상 메모, 갤러리별 관리 |
| 레이아웃 수정 | 디시 레이아웃을 변경할 수 있도록 도와줍니다. |
| 폰트 교체 | 페이지에 전반적으로 표시되는 폰트를 교체합니다. |
| 스텔스 모드 | 페이지내에서 표시되는 이미지를 비활성화합니다. |
| 이미지 검색 | 이미지를 검색합니다. |
| 글쓰기 | 글쓰기 페이지를 변경합니다. |
| 관리 | 무급 노예들을 위한 여러 편의 기능을 제공합니다. |
| 데이터 관리 | 클라우드 백업/복원, JSON 내보내기/가져오기 |
